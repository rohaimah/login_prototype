# Login Prototype
A basic login UI/UX prototype designed in Figma showcasing simple authentication screen design.

𝑻𝒐𝒐𝒍 𝑼𝒔𝒆𝒅:

• Figma


𝑷𝒓𝒐𝒄𝒆𝒔𝒔:

I started by searching and thinking about how a simple login screen should look and what users usually need when signing in. I then built the layout in Figma using basic shapes and inputs like email and password. I adjusted the spacing and arrangement until it felt clear and easy to use. After that, I added a simple prototype flow to show how the login interaction would work when a user clicks the button.

𝑭𝒆𝒂𝒕𝒖𝒓𝒆𝒔:

• Clean login layout

• Email and password input design

• Simple and minimal UI structure

• Prototype flow for login interaction

This project was created as part of UI/UX practice to understand layout design, user flow, and interface simplicity in authentication systems.
